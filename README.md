# Data Science for Physics

This repository contains exercises, exams, and computational work developed for the course **Introduction to Data Science**, offered as part of *Temas Selectos de Física Computacional III* at the Faculty of Sciences, UNAM.

The course provides a practical introduction to data science and machine learning, with emphasis on working with real and synthetic datasets using Python.

Topics covered include:

* Python for data analysis
* Exploratory data analysis
* Iris and MNIST datasets
* Global temperature datasets
* Synthetic datasets
* k-Nearest Neighbors (k-NN)
* Classification problems
* Dimensionality reduction
* Simple, multiple, and polynomial regression
* Decision trees
* Artificial neural networks

The repository focuses on implementing these techniques computationally and developing practical skills for data analysis, modeling, and machine learning.
